# Quiz-Game

Built a dynamic quiz game from scratch using the holy trinity of front-end development: HTML for structure, CSS for style, and JavaScript for logic. this project challenged me to manipulate the DOM, manage state with JavaScript, and create a responsive, score-keeping quiz experience.

Think you know your stuff? Put your knowledge to the test with my interactive quiz game. Get ready for instant feedback and a final score that doesn't lie.
No server. No databases.
